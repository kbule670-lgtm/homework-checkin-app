# 测试说明

> 测试号、测试班、测试作业都在 `supabase/seed_test_data.sql` 里 seed，
> 执行前先读那份文件顶部的说明（auth.users 不能只用 SQL 插）。

## 一、测试号（占位格式）

| 角色 | 手机号（登录账号） | 密码 | 姓名 |
|------|------------------|------|------|
| 老师 | 13800000001 | Test123456 | 测试老师 |
| 学生 1 | 13800000002 | Test123456 | 测试学生甲 |
| 学生 2 | 13800000003 | Test123456 | 测试学生乙 |

- 这三个号**不是**已经注册好的账号：必须先在 App 注册页注册（或在 Supabase
  Dashboard → Authentication → Add user 里添加），再到 Users 里复制真实 uuid，
  替换 seed 文件里的占位 uuid 后执行 seed。
- 手机号只是登录用的账号名，不会真的发短信；密码 `Test123456` 只用于测试，
  不要拿去注册正式账号，也不要把真实手机号写进代码或文档。

## 二、准备工作

1. 在 Supabase Dashboard → SQL Editor 里执行 `supabase/schema.sql`（建表 + RLS）。
2. 在 Dashboard → Storage 里确认 `homework-photos` bucket 已建好
   （schema.sql 里已含建 bucket 的 SQL，执行成功即建好）。
3. 部署 Edge Function（只影响 PDF 导入测试）：
   `supabase functions deploy pdf-extract`。
4. 按上面第一节注册三个测试号，替换 uuid，执行 `supabase/seed_test_data.sql`。
5. 在 `lib/app_config.dart` 填入 Supabase 地址和 anon key（占位格式，
   真实值只填在本地配置文件里，不提交、不写进文档）。

## 三、一台手机走完一圈（核心流程）

1. **老师发作业**：登老师号（13800000001）→ 进测试班（邀请码 TEST01，
   seed 已建好）→ 发一份做题作业（可用 seed 里的“测试作业：英语选择填空”，
   或自己新建一份、从 Excel/txt 导入 3 道题）→ 记下作业标题和截止时间。
2. **退出**：我的 → 退出登录。
3. **学生交作业**：登学生 1 号（13800000002）→ 输邀请码 TEST01 进班 →
   打开作业 → 做题提交（选择题自动判分，填空对不上会标需老师复核）→
   再用学生 2 号交一份拍照作业（拍照张数不限，拍 2 张以上试试）。
4. **退出**：再登回老师号。
5. **老师批改**：进作业 → 看统计（已交/应交/迟交数，与 completion_stats
   视图一致）→ 点开学生 1 的提交 → 打分 + 写评语 → 保存 →
   确认该提交状态变成“已批改”。
6. **学生查看**：退出登学生 1 号，确认能看到分和评语；再点一次“提交”，
   应提示“已批改，不能重交”。

## 四、迟交测试

把一份作业的截止时间改成 1 小时前，再用学生号交一次：提交后应标成迟交
（`is_late = true`，状态 `late`），老师端统计里的迟交数 +1。

## 五、电脑安卓模拟器双开（想同时看老师端和学生端）

- 电脑上装 Android Studio → Device Manager → 新建一台模拟器（Pixel 系列即可）。
- 模拟器里装 apk 当“第二台手机”登学生号，真机登老师号，两边同时在线：
  老师发作业 → 模拟器里的学生端应能收到新作业通知（App 内轮询）。
- 没电脑时也可以借同学一台安卓手机装 apk 当学生端，效果一样。

## 六、导入测试（每种格式至少测一次）

- Excel / CSV / JSON / txt：用 `docs/IMPORT_TEMPLATES.md` 里的模板各导 3 道题，
  确认题数、选项、答案、分值都对；缺答案的题应保留下来（answer 为空），
  发作业前 App 应提醒老师补全。
- Word：用 .docx 测一次；再拿一个老版 .doc 测一次，应提示“另存为 .docx”。
- PDF：文字版 PDF 测一次（应成功）；扫描版 PDF（手机拍的题、图片拼的）
  测一次，应提示“这是扫描版 PDF，没有文字层，请转文字版 PDF 再导入”。

## 七、测试数据与正式数据分开

- 测试只用 TEST01 测试班和三个测试号；正式卖给老师后，老师自己建班、
  学生自己注册，数据天然分开。
- 测坏了重来：执行 seed 文件末尾的清空 SQL（按 `invite_code = 'TEST01'`
  删除测试班，级联清掉名下作业、题目、提交、批改与成员），再重新执行 seed。
- 测试账号想连号一起删：去 Dashboard → Authentication → Users 里删，
  SQL 删不掉 auth.users 的账号。
- 正式数据（真实老师和学生）绝不能用清空 SQL 删，清空语句只认 TEST01。
